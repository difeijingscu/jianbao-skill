# 信源政策与核实规则

简报的价值全部来自可追溯。这一页的规则优先级高于"写得好看"。

## 一、信源分级

| 级别 | 类型 | 用法 |
|---|---|---|
| **S1 一手** | 官方公告、新闻通稿、财报、监管文件、会议官方议程、当事方官网 | 事实与数字的最终依据，优先引用 |
| **S2 权威媒体** | 新华社/新华网、人民日报、央视、上海证券报·中国证券网、澎湃、财新、第一财经、浙江在线、潮新闻等 | 用于核实 S1 未覆盖的内容，可单独作为观点出处 |
| **S3 行业与专业** | 行业协会、研究机构报告、专业垂直媒体、学术论文 | 用于背景与趋势判断，需注明机构与发布日期 |
| **S4 弱信源** | 自媒体、社交平台、聚合站、无署名转载 | **不作为唯一依据**；只能用于"发现线索"，必须回到 S1/S2 验证 |

规则：
- 每个关键结论至少 1 条 S1 或 S2。
- 同一事实出现两家以上 S2 互相矛盾时，**两个口径都写出来并标注分歧**，不要择一。
- 只有 S4 支撑的内容，一律不写入正文；确有价值则写入"待确认"。

## 二、核实顺序

1. **先找一手**：官方通稿 / 议程 / 公告 / 财报。数字优先取这里。
2. **再补观点**：谁在什么场合说了什么。观点必须能定位到"人 + 场合 + 时间"。
3. **交叉验证**：关键数字至少两个独立来源；只有一家就标"单一来源，待验证"。
4. **反向检查**：有没有与该结论相反的证据？有就写进"风险与不确定性"。

## 三、数字纪律

| 要求 | 说明 |
|---|---|
| 带口径 | 写"12.8 万人次（累计到场，官方口径）"，不写"12.8 万" |
| 带时点 | 数字对应哪一天/哪个窗口，必须可定位 |
| 不改精度 | 原文 7.076 ms 就写 7.076，不四舍五入成 7.06 |
| 不跨年混用 | 上届/上一期的数字要标年份，不能与本届并列当同一口径 |
| 不换算不推测 | 需要换算（百分比、同比）时写出计算式，或标注"据…测算" |
| 单位统一 | 中文数字与阿拉伯数字不混排；亿/万统一 |

**用错数字比没有数字危害大。** 拿不准就写"官方未披露"。

## 四、时效标注

- 页眉 `meta_line` 必写"信息截至 YYYY-MM-DD HH:MM"。
- `sources[].date` 必填，缺失会在体检时报 W2。
- 正文提到计划、预期、路线图时，写清"计划/预计/目标"字样，并注明发布日期——**计划不是事实**。
- 政策、法规类内容必须核对现行有效性（是否已废止、是否已修订），并在 note 里说明核对日期。

## 五、引文与观点

- 引号内必须是原文，不得改写、缩写、拼接。
- 转述时保留限定语："表示""预计""目标是"，不要升级为"宣布""确定"。
- 译名、产品名、机构名以官方中文口径为准；官方未给中文名时保留英文原名。
- 同一主体在不同场合口径不一致时，注明场合差异，不要合并成一句。

## 六、禁止项

- 编造数字、日期、引文、机构名、人名。
- 用"业内普遍认为""有分析指出"代替具体信源。
- 把推断写成事实（"这说明…"可以，"事实证明…"不行）。
- 用上一期的数据顶替本期（复用模板时最容易犯）。
- 把预测当结果、把目标当成绩。

## 七、sources 记录格式

```json
{"publisher": "新华网", "title": "文章标题", "date": "2026-10-29", "url": "https://…"}
```

- `publisher` 写媒体/机构名，不写"网络"。
- `title` 与原标题一致，不改写。
- 一条信源只对应一篇材料，不要把多篇合并。
- 页面上按顺序编号 `[1] [2] …` 展示，正文无需逐句标号，但 note 里要说明哪类信息来自哪几条。
